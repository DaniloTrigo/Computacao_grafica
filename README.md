# Formiga Robô — Computação Gráfica

Projeto desenvolvido em C++ utilizando OpenGL para a disciplina de Computação Gráfica.

O projeto consiste em uma formiga robótica tridimensional com estrutura articulada, texturas, iluminação e interação por teclado.

## Funcionalidades

- Cabeça articulada
- Dois olhos
- Duas antenas articuladas
- Tórax
- Abdômen
- Seis pernas articuladas
- Animação de caminhada
- Movimentação independente das pernas
- Movimentação independente da cabeça
- Movimentação independente das antenas
- Rotação da formiga
- Zoom da câmera
- Pan da câmera
- Órbita da câmera
- Iluminação OpenGL
- Materiais e reflexão especular
- Texturas BMP
- Projeção perspectiva

## Tecnologias

- C++
- OpenGL
- GLU
- FreeGLUT
- RgbImage
- Visual Studio 2022
- Windows x64
